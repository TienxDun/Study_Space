Quy Trình Kiểm Tra Bảo Mật 4 Chặng

Nguyên tắc Zero-Trust: xác thực phía server, không lưu token tại client
01 / REQUEST 💻
Trình duyệt Client

Gửi yêu cầu GET /api/admin/overview hoàn toàn không đính kèm secret token.

02 / EDGE GATE 🛡️
Cloudflare Access

Kiểm tra thông tin đăng nhập email và cấp JWT trước khi request tới Worker.

03 / SIGNATURE 🔑
Admin Worker

Giải mã chữ ký RS256 JWT độc lập, từ chối 401 ngay lập tức nếu thiếu quyền.

04 / SNAPSHOT ⚡
Cụm Worker

Gộp sức khỏe, chat, đồng bộ và LiveKit vào một snapshot; nguồn nào lỗi thì khối đó báo đỏ.
